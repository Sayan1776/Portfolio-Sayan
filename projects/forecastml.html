WORK / 03 / PYTHON

ForecastML — Kolkata.

A weather prediction experiment using historical observations and a Random Forest model.

LEARNING PROJECTPYTHON · MACHINE LEARNING · DATA VISUALIZATION
GitHub repository ↗
KOLKATA / WEATHER SIGNAL
2017—2022RANDOM FOREST

01 / THE PROBLEM

Start with a clear question.

I wanted a practical ML project with a place, a dataset, and an output that could be explored. ForecastML uses historical Kolkata weather data from 2017–2022 for a seven-day forecasting experiment.

02 / DESIGN DECISIONS

Dataset

Work with historical weather observations rather than inventing sample values.

Model

Use RandomForestRegressor as an approachable baseline for a regression task.

Presentation

Use Plotly to make the output easier to inspect than raw terminal numbers.

Limitations

Treat the result as an experiment; meaningful forecasting needs proper validation and comparison with baselines.

WHAT I TOOK AWAY

  • ✳A model is only as useful as the evaluation around it.
  • ✳Charts help inspect trends but do not prove a model is accurate.
  • ✳Data preparation is a real part of the project, not just a prelude to training.

03 / NEXT ITERATION

What I’d improve next.

Add time-aware train/test splits, compare against a simple baseline, and report error metrics before making stronger claims.
