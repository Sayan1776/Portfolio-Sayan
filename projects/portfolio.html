01 / THE PROBLEM

Presenting a broad set of experiments without turning the site into a noisy project dump.

The portfolio combines editorial typography, a project index, motion-based entry and scroll states, skill-network visualization, and a contact flow. This was an earlier chapter that informed the more personal Fieldnotes design.

02 / DESIGN DECISIONS

Documentary design

Use high contrast, restrained accent colour, and typographic hierarchy to set the tone.

Project navigation

Keep a searchable/filterable project view rather than a long unstructured list.

Motion system

Use entry and scroll animations to reveal information in a controlled sequence.

Contact workflow

Use a form endpoint rather than implying a static page has its own mail server.

WHAT I TOOK AWAY

  • ✳Motion should support hierarchy, not interrupt reading.
  • ✳A site becomes easier to explore when projects can be filtered.
  • ✳Design decisions should be reusable across pages.

03 / NEXT ITERATION

What I’d improve next.

Keep simplifying the project story, review accessibility for motion and contrast, and maintain case-study pages as projects evolve.
