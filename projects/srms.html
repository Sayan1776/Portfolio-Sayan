Student Record Management System.

A small console project for records, control flow, and the basics of managing data.

01 / THE PROBLEM

Start with a clear question.

The goal was straightforward: practice the basic workflow of storing and retrieving student records, validating user input, and separating small tasks into understandable functions.

02 / DESIGN DECISIONS

Simple flows

Keep add, find, list, and update actions clear for a console user.

Input validation

Handle empty or unexpected input instead of assuming the happy path.

Readable structure

Use the project as a place to practice function boundaries and data representation.

WHAT I TOOK AWAY

  • ✳Input validation is part of the feature, not a bonus.
  • ✳Small CLI apps teach important interaction edge cases.
  • ✳Naming data clearly keeps basic programs maintainable.

03 / NEXT ITERATION

What I’d improve next.

Add persistent storage and automated tests once the core record operations are stable.
